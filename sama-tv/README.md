# سما · شاشة توقف ساعة وطقس لشاشات Google TV

شاشة توقف عربية للزعفرانية في بغداد. السماء بيها تتغير حسب الطقس الحقيقي والوقت: الغيوم تمشي بسرعة الريح، والمطر ينزل وتطلع دوائر على سطح دجلة، والبرق يضرب بالعاصفة، والعجاج يصفّر السماء، وبالليل تطلع النجوم والقمر بطوره الصحيح وتضوي شبابيك البيوت. أفق المدينة هو أفق بغداد: برج بغداد، ونصب الشهيد، والقباب، والمنائر، والنخيل.

## شنو تعرض

- **ساعة كبيرة** بالأرقام العربية، وتحتها خط يمشي مع الثواني.
- **التاريخ** بأسماء الأشهر العراقية (تشرين الأول، كانون الثاني…) والتاريخ الهجري.
- **الطقس الحالي**: الحرارة، والإحساس، والعظمى، والصغرى.
- **الساعات الجاية**: سبع ساعات، وويّاها احتمال المطر.
- **قوس الشمس**: وين صارت الشمس هسه، ووقت الشروق والغروب، وطول النهار.
- **الأيام الجاية**: أربعة أيام، وكل يوم عليه شريط يبين مدى الحرارة.
- **التفاصيل**: الرطوبة، والرياح واتجاهها، والأشعة فوق البنفسجية، وجودة الهواء.
- **جملة ذكية** تتغير حسب الحالة، مثل: «احتمال مطر ٧٠٪ الساعة ٧ م»، أو «غبار في الجو، الأفضل تسدّ الشبابيك»، أو «هوا شرجي رطب»، أو «باچر أبرد بـ ٤ درجات».

## الحالات المتحركة

صحو، ليل صافٍ، شروق وغروب، غيوم متفرقة، غائم، رذاذ، مطر، عاصفة رعدية، رياح قوية، عاصفة ترابية، ضباب، حر شديد (فوق ٤٤°)، وثلج.

## حماية الشاشة

- كل دقيقة ونص تتحرك الكتابة شوية من مكانها، حتى ما تنطبع على الشاشة.
- من الساعة ١٢ بالليل لحد ٦ الصبح، الإضاءة تخف تلقائياً.
- الرسم مقيّد بـ ٣٠ إطار بالثانية وبدقة مخففة، حتى يبقى خفيف على معالج الشاشة.

## التنصيب

1. نزّل `sama.apk` من صفحة الإصدار:
   https://github.com/thedeerm/JOKER/releases/tag/sama-latest
2. نصّبه على الشاشة، بوحدة من طريقتين:
   - **من الكمبيوتر**: اكتب `adb install -r sama.apk`
   - **من الشاشة نفسها**: استخدم تطبيق Downloader، واكتب بيه الرابط المباشر:
     `https://github.com/thedeerm/JOKER/releases/download/sama-latest/sama.apk`
3. خليه شاشة التوقف. Google TV ما يخليك تختار شاشات التوقف الخارجية من الإعدادات، فلازم تستخدم أوامر ADB:

```bash
adb shell settings put secure screensaver_components iq.joker.sama/.SamaDream
adb shell settings put secure screensaver_enabled 1
# اختياري: تشتغل بعد ٥ دقايق بدون استخدام
adb shell settings put system screen_off_timeout 300000
```

حتى تجربها هسه بدون ما تنتظر (هذا الأمر ما يشتغل على كل الشاشات، وإذا ما اشتغل، اترك الريموت وانتظر لحد ما يخلص الوقت):

```bash
adb shell am start -n com.android.systemui/.Somnambulator
```

حتى ترجع شاشة التوقف الأصلية مال Google:

```bash
adb shell settings put secure screensaver_components com.google.android.apps.tv.dreamx/.service.Backdrop
```

## التجربة كتطبيق

افتح تطبيق **سما** من قائمة التطبيقات. بالأسهم ◀ ▶ تتنقل بين كل حالات الطقس وتشوف حركتها، وزر الوسط يرجعك للطقس الحقيقي.

وتكدر تفتح الملف `app/src/main/assets/sama/index.html` بأي متصفح على الكمبيوتر. وإذا تريد تشوف حالة معينة، ضيف لآخر الرابط مثلاً `?demo=6` (عاصفة رعدية) أو `?demo=8` (عاصفة ترابية).

## التعديل

- **المكان**: بأول ملف `app/src/main/assets/sama/app.js` تلگى `CONFIG`، وبيه الاسم وخط العرض وخط الطول.
- **بيانات الطقس**: من [Open-Meteo](https://open-meteo.com)، مجانية ومن دون مفتاح.
- **الخط**: Readex Pro (رخصة OFL، موجودة بمجلد `fonts`).
- **البناء**: GitHub Actions يبني التطبيق تلقائياً كل ما يتغير شي بمجلد `sama-tv` (الملف `.github/workflows/sama-apk.yml`)، وينشره بنفس رابط الإصدار.
- **مفتاح التوقيع** `app/sama.keystore` موجود بالمستودع عن قصد، حتى كل نسخة جديدة تتنصب فوق القديمة بدون مشاكل. هذا تطبيق شخصي، مو للنشر على المتجر.
